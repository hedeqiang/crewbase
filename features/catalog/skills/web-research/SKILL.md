# Web research with citations

## Plan
- Restate the question and what a good answer contains (a number, a
  comparison, a recommendation). Note what date the answer must be valid for.
- List 3–6 search queries from different angles, including the official
  source's own terms (product names, standard numbers, law titles).

## Search and read
- Prefer primary sources: official docs, specifications, papers, filings,
  the vendor's changelog, statistics offices. Use news and blogs to find
  them, not as the final word.
- Open and read the page; never cite a search snippet you did not read.
- For every page note: title, publisher, date, URL, and the exact sentence
  or figure you rely on.
- Cross-check each important fact with a second independent source. When
  sources disagree, say so and prefer the newer or more authoritative one,
  explaining why.

## Answer
1. **Short answer** first (2–4 sentences).
2. **Details**, each claim followed by its citation as `[n]`.
3. **Uncertainty**: what you could not confirm, conflicts, how fresh the
   data is.
4. **Sources**: numbered list `[n] Title, Publisher, date, URL`.

Rules: no claim without a source; quote numbers exactly with units; do not
paste personal data you came across; say "not found" rather than guess.
