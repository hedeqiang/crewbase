# ADR-0003 团队（Team）：在「整台主机」和「频道」之间加一层

状态：接受（2026-11-15）：一人项目空间与多人协作都支持；公开、私密都支持。第一期已实现。

## 现状

| 概念 | 现在是什么 | 范围 |
|---|---|---|
| 成员与角色 | 能连到这台 Crewbase 的**人**：admin / member / viewer，按动作类别授权审批；用配对的设备登录 | 整台主机，没有分组：每个人看到全部 Agent、频道、对话 |
| 频道 | 一个**工作房间**：几个 Agent（加上人）共享上下文，同一时刻一个负责人，显式交接 | 单个任务 / 话题 |
| 文件夹 | 侧边栏里把对话、频道归类 | 只是展示分组，不管权限 |

缺的是中间那一层：一群人 + 一组 Agent + 他们的频道，以及这组共享的东西（记忆、连接、规则、预算）。现在「成员」相当于 Slack 的工作区成员，但没有「团队」。

## 市场上的做法

三层结构几乎是共识：**容器 → 团队 → 工作单元**，权限按层收紧。

| 产品 | 容器 | 中间层 | 工作单元 | 要点 |
|---|---|---|---|---|
| Notion | 工作区（所有者 / 管理员 / 成员 / 访客） | Teamspace：所有者 / 成员；公开、封闭、私密三种 | 页面 | 工作区设置是上限，Teamspace 只能更严 |
| Linear | 工作区 | Team（可嵌套子团队；可设私密） | Issue、项目 | 任务属于团队，流程按团队配置 |
| Slack | 工作区 | 用户组（@designers，带默认频道） | 频道 | 组用来批量加人进频道 |
| ChatGPT Business | 工作区 | Teams：做同一批项目的人 | 共享 Agent：按人授予「可用 / 可编辑」 | 工作区 Agent 在组织权限内运行 |
| Lindy | 工作区（Owner / Admin / Member） | — | Agent | 共享连接、团队共享记忆 |

参考：[Notion teamspaces](https://www.notion.com/help/intro-to-teamspaces)、[Notion 权限](https://www.notion.com/en-gb/help/guides/grant-access-teamspaces)、[Linear Teams](https://linear.app/docs/teams)、[Linear 子团队](https://linear.app/docs/sub-teams)、[Slack 用户组](https://slack.com/help/articles/212906697-Create-and-edit-user-groups)、[ChatGPT workspace agents](https://help.openai.com/en/articles/20001143-chatgpt-workspace-agents-for-enterprise-and-business)、[Lindy 团队](https://www.lindy.ai/docs/start-here/team-setup)。

和它们相比，我们的不同在于成员里不只有人，还有 **Agent**：团队是「人 + Agent」的编组，Agent 也只在自己的团队里被看见、被委派。

## 提议的模型

```
主机（一台 Crewbase）
├─ 人：主机角色 所有者 / 管理员 / 成员 / 访客 —— 谁能进来（现在的「成员与角色」）
├─ 个人空间：每个人自己的新对话、私人 Agent（别人看不到）
└─ 团队（可建多个）
   ├─ 团队成员：人（团队角色 负责人 / 成员 / 只读）+ Agent（属于这个团队）
   ├─ 频道：团队里的工作房间（单一负责人、交接——不变）
   └─ 团队共享：团队记忆 TEAM.md、连接（MCP、凭证引用）、默认运行权限与规则、
                 IM 群绑定、用量与预算、主理人
```

- **团队和频道的关系**：团队决定「谁、哪些 Agent、什么权限和资源」；频道是团队里一件具体工作的房间。频道只能拉本团队的 Agent 和人；队友名册、委派、主理人的分派范围也都限定在团队内。
- **权限**：主机设置是上限，团队只能更严（同 Notion）。人看得到：个人空间 + 自己加入的团队 + 公开团队（只读，可申请加入）。审批按「人在这个团队的角色」判定，支付仍然永远不能远程批准。
- **一个人用也有意义**：团队同时是「项目空间」——比如「电商店铺」「开源项目」各一个团队，Agent、频道、记忆、连接互不串。
- **界面**：侧边栏顶部是团队切换（个人 / 团队 A / 团队 B），下面是该团队的频道和 Agent；设置里「成员与角色」改为两页：主机成员、团队管理（建团队、加人、加 Agent、团队设置）。

## 迁移

升级后自动建一个「我的团队」，现有 Agent 和频道都放进去；现有成员按原角色加入它。只有一个团队时界面和现在一样，建了第二个团队才出现切换器。

## 分期

1. **团队骨架** ✅：建 / 改 / 删团队（公开 / 私密）；Agent、频道归属团队；侧边栏切换；名册、委派、频道拉人限定在团队内；Agent 在团队间移动。
2. **人和权限** ✅：团队成员与团队角色；公开 / 私密；按团队判定可见范围和审批；个人空间。
3. **团队共享**：团队记忆、共享连接、团队默认规则、IM 群绑定到团队、用量按团队统计。
