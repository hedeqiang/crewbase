# 术语表

每个概念只用一个规范用词。带 † 的术语沿用 DeepSeek Harness 的定义。

## 产品

| 术语 | 定义 |
|---|---|
| Agent | 有名字、角色、工作目录、记忆、队列的持久执行体。模型是它使用的零件，不是它的身份 |
| 频道（Channel） | 多个 Agent 与人类成员共享上下文和文件引用的协作空间 |
| 负责人（Task Owner） | 频道中当前推进任务的唯一 Agent |
| 交接（Handover） | 负责人把任务、说明和产物文件显式移交给另一个 Agent |
| 运行模式 | 只读调研 / 容器沙箱 / 宿主机授权三个权限预设 |
| 规则 | 按动作类别配置的 Allow / Ask / Block |
| 审批 | 规则为 Ask 时，人对一次具体调用做出的决定 |
| 接管 | 人临时控制 Agent 的浏览器，期间 Agent 暂停 |
| Routine（例行巡检） | 按 Cron 或 Webhook 触发的单 Agent 例行任务，无异常时静默 |
| Workflow（工作流） | 触发器 → 多 Agent 串并行步骤 → 审批卡点 → 发布的可复用流水线 |
| 晨报 | 每天汇总需要人处理的事项的 Routine |
| 模型顺序 | 一个 Agent 按优先级排列的模型列表，额度耗尽时依次切换 |
| 主机 | 运行 `crewd` 的机器：本机或远程服务器 |

## 插件系统

| 术语 | 定义 |
|---|---|
| 插件宿主（kernel） | 唯一不可替换的部分：服务注册表、事件总线、副作用跟踪、依赖解析、Profile 加载、进程外桥接 |
| 插件 † | 声明依赖后，向上下文注册服务、监听和副作用的单元 |
| 上下文（Context）† | 服务的容器；每个服务占据一个稳定的键 |
| 服务键 † | 服务在上下文中的名字，如 `tools`、`llm`、`sandbox` |
| PENDING † | 插件的依赖尚无人提供时的等待状态，不是错误 |
| 副作用（Effect）† | 任何注册；必须有对应的撤销函数，插件卸载时按逆序撤销 |
| 分发模式 † | `Emit` / `Waterfall` / `Parallel` / `Serial` / `Bail` |
| 短路 † | Waterfall 监听方不调用 `next()` 直接返回，下游不再执行 |
| 能力（seam）† | 一项可替换能力：定义 + 提供方 + 消费方。单一角色不叫能力 |
| 作用域（Scope）† | 注册的可见单位：全局或某个 Agent，两层扁平结构 |
| 覆盖（Shadowing）† | Agent 作用域内的同名注册替换全局版本 |
| 限制（Restriction）† | 为某个 Agent 过滤全局工具集合，多个限制取交集 |
| 组装窗口（Setup window）† | 创建 Agent 时专用于注册其私有工具和提示词的时机 |
| 父子关系（Lineage）† | 子 Agent 的来源信息，以数据记录，不影响可见性 |
| 组合包（Bundle）† | 一组插件条目及其配置的分发单位 |
| Profile † | 具名组装：组合包列表 + 第三方插件 + 用户补丁 |
| 补丁（Patch）† | 按条目 `id` 替换、插入或禁用插件条目的配置层 |
| 守卫 † | 工具流水线中只能拒绝或弃权、不能放行的检查 |
| 插槽（Slot）† | 界面扩展点，插件在此注册组件 |

## 会话与循环

| 术语 | 定义 |
|---|---|
| 会话日志 † | 仅追加的事件日志，模型历史、界面、审计都从它投影 |
| 模型可见即已记录 † | 每次模型请求都必须能从会话日志重建 |
| 步骤（Step）† | 一次模型请求，加上它引发的工具执行 |
| 轮次（Turn）† | 处理完一批已接收输入的过程，包含零到多个步骤 |
| Round † | 外层策略的一次迭代，如目标续跑的一轮、工作流的一步 |
| 目标（Goal）† | 附着在会话上的持久完成目标：进行中 / 暂停 / 阻塞 / 完成，有轮次上限 |
| 压缩（Compaction）† | 上下文占用达到阈值时，用摘要替换较早区间 |
| 投影（Projection）† | 从会话事件折叠出的只读视图，供界面和服务读取 |
